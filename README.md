# 🏇 競馬予測AI

競馬のレース結果を予測するAIモデルです。  
- 回収率130％達成

---

## 📌 概要

本プロジェクトは、機械学習を用いて競馬レースの予測を行うシステムです。

- 過去レースデータを学習
- 馬・騎手・コースなどの特徴量を利用
- 勝率や順位を予測

---

## 🎯 主な機能

- レース結果の予測（1着 / 上位）
- 勝率の算出
- 特徴量の生成（例：騎手勝率、距離適性など）
- モデルの学習・評価
- 予測結果の可視化

---

## 🧠 使用技術

- 言語: Python
- ライブラリ: 
  - pandas
  - numpy
  - scikit-learn / LightGBM / XGBoost
- 可視化: matplotlib / seaborn
- その他:
  - Jupyter Notebook
